# Celyah Robot V8 — واجهات مطورة

مشروع Flutter جديد مستوحى من هوية الروبوت (أسود + لافندر `#F08DEB` + Celyah♡).
هذا **سورس تجريبي** وليس APK تم اختباره أو بناؤه بنجاح.

## الواجهات
- الرئيسية: وجه كبير مرسوم ببرنامج Flutter، شعار نصي Celyah♡ ROBOT، اختصارات Talk / Vision / Control.
- المحادثة: مؤشر حالة Celyah، إدخال نص، ميكروفون speech_to_text، نطق الردود flutter_tts مع خيار إيقافه.
- الرؤية: شاشة انتظار البث + اختبار `CAM` عبر BLE. لا يوجد بث فيديو فعلي بعد.
- التحكم: إيقاف/إلغاء واختبارات الذراع. لا توجد قيادة للعجلتين FS90R حتى تثبيت بروتوكول الأوامر.
- الإعدادات: BLE وخيار الصوت.

## قيود
- شعار Celyah مكتوب بخط النظام، وليس ملف شعار أصلي مطابق 100%.
- التعرف على الوجوه والعوائق والحواف غير منفذ بعد.
- الكلام يمر عبر BLE للروبوت؛ Gemini ليس مدمجًا مباشرة في هذا التطبيق.
- واجهة الصوت تتطلب صلاحية ميكروفون وخدمات التعرف على الكلام على الجهاز.
- لم يتوفر Flutter SDK محليًا لاختبار البناء؛ راجع GitHub Actions قبل اعتماد APK.
- لا تختبر حركة ذاتية قرب حواف أو سلالم.

## البناء
1. ارفع محتويات ZIP إلى مستودع GitHub.
2. افتح Actions وشغّل `Build Celyah V8 APK`.
3. راجع سجل البناء، ثم نزّل Artifact `Celyah-V8-APK` عند نجاح البناء.
4. احتفظ بنسخة التطبيق القديم حتى تتأكد من الاتصال.
